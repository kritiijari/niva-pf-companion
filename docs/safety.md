# Safety and privacy

NIVA displays a synthetic-data / not-official-service notice throughout. It neither connects to EPFO nor requests Aadhaar, PAN, UAN, bank numbers, passwords, or OTPs. Client text is capped and sensitive-looking number patterns are redacted before structured logging. Raw document content is neither persisted nor logged. API keys live in the backend environment only.

The deterministic engine is authoritative. Unsupported cases are marked for clarification instead of being guessed. This prototype gives workflow guidance, not legal or eligibility determinations.
